# COOPs 議事録AI v4.0 — セットアップ＆デプロイ手順書

GitHub + Vercel での本番リリースと、高速化・セキュリティ改修を行った新規環境の構築手順です。

---

## 1. Google スプレッドシート ＆ GASの作成

1. Google Driveで **新しい Google スプレッドシート** を作成します。
   （※既存のシートからデータを引き継ぐ場合は、シート内容を新しいスプレッドシートにコピペしてください）
2. メニューの **「拡張機能」 → 「Apps Script」** を開きます。
3. デフォルトの `コード.gs` を開き、本プロジェクトの [Code.gs](file:///c:/Users/mshim/OneDrive/Desktop/COOPs-担当者会議議事録AI/Code.gs) のコードを全選択して上書き保存します。
4. 左メニューの **「プロジェクトの設定（歯車マーク）」** を開き、画面下部の **「スクリプト プロパティ」** を追加します。
   - プロパティ名: `GEMINI_API_KEY`
   - 値: `あなたのGemini APIキー (AIzaSy...)`
   - 「スクリプト プロパティを保存」をクリックします。
5. 右上の **「デプロイ」 → 「新しいデプロイ」** を選択します。
   - 歯車アイコンから **「ウェブアプリ」** を選択
   - 説明: `v4.0 Web API`
   - 実行するユーザー: **`自分`**
   - アクセスできるユーザー: **`全員`**
   - 「デプロイ」ボタンをクリックし、アクセス権限を承認します。
6. デプロイ完了画面に表示される **「ウェブアプリのURL」**（`https://script.google.com/macros/s/.../exec`）をコピーします。

---

## 2. GitHub ＆ Vercel へのデプロイ

1. 本リポジトリ（`index.html`, `Code.gs` 等が含まれるフォルダ）を **GitHub** に Push します。
2. **Vercel** (`https://vercel.com`) にログインし、**「Add New」 → 「Project」** を選択します。
3. 先ほどPushした GitHub リポジトリを選択し、**「Deploy」** をクリックします。
   - フレームワーク等の設定は不要です（`index.html` がそのままホスティングされます）。
4. デプロイ完了後、Vercelから発行された公開URL（`https://xxx.vercel.app`）にアクセスします。

---

## 3. アプリの初回設定

1. Vercelの公開URLにアクセスすると、初回起動時に「⚙️ GAS API エンドポイント設定」画面が表示されます。
2. 手順1の最後にコピーした **GASの「ウェブアプリのURL」** を入力し、「設定を保存」をクリックします。
3. これで設定完了です！高速化された議事録AIが利用可能になります。

---

## 💡 ボトルネック解消のポイント

- **ログ一覧の爆速化**: ログ一覧を開く際は数文字のメタデータのみを取得（データ通信量を90%削減）。
- **モーダルオンデマンド読み込み**: 「表示」を押したログだけを1件ずつ個別に読み込む仕様に変更。
- **セル更新の高速化**: セルへの個別アクセスを廃止し、`setValues` で一括保存。
- **セキュリティの保護**: APIキーはソースコードから排除され、GASの `PropertiesService` 内で保護されます。
