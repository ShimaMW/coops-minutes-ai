# carecore 担当者会議AI議事録（カイポケ ＆ iBow / コパン訪問看護ステーション対応版）

carecore のデザイントンマナを維持しつつ、介護ソフト「カイポケ」および訪問看護記録ソフト「iBow（コパン訪問看護ステーション向け）」の両対応、ブラウザ直接通信による高速AI音声解析（Gemini 3.6 Flash ＋ 自動リトライ・モデルフォールバック）、長時間録音（Screen Wake Lock API）を備えた最新版の仕様・手順書です。

---

## 💡 主な機能とアップデート内容

1. **出力先ソフトのワンタッチ切替（カイポケ用 ／ iBow用）**
   - **カイポケ用（居宅介護支援）**: 「全体要約」および「①検討した項目」「②検討内容」「③結論」「④残された課題」の5つの窓に分割出力。
   - **iBow用（コパン訪問看護ステーション）**: iBowの単一入力ウインドウ仕様に合わせ、窓を分けず**1つのテキストエリアに全文を集約**。「コパン訪問看護ステーション」が提供するケア内容・役割・決定した具体的なToDoに強くフォーカスして生成します。
2. **会議名・開催区分の選択とAIプロンプト連動**
   - 「会議名（サービス担当者会議／退院支援指導カンファレンス／退院共同指導カンファレンス／その他会議）」と「実施の理由・開催区分（更新／新規／区分変更・状態変化／退院・退所時／サービス追加／定期・その他）」を選択可能。
   - 過去ログの上書き保存・新規保存・一括コピー・CSV出力にも完全連動します。
3. **ブラウザ直接 Resumable Upload ＆ 自動リトライ・モデルフォールバック**
   - Vercel の容量制限（4.5MB）や実行時間上限（60秒）を回避するため、ブラウザから Google Files API / Gemini API へ直接通信します。
   - `429`（レート制限）や `503`（過負荷）発生時は、音声の再アップロードなしで指数バックオフ待機＆予備モデル（`gemini-3.6-flash` ➔ `gemini-3.5-flash` ➔ `gemini-2.5-flash`）へ自動フォールバックします。
   - 解析終了後は `finally` ブロックで Google サーバー上の一時音声ファイルを即時 `DELETE` します。
4. **ブラウザ長時間録音（Screen Wake Lock API ＋ 波形表示）＆ ボイスメモ両対応**
   - 録音中は `navigator.wakeLock` によりスマホ・タブレットの画面消灯を防止し、一時停止・再開、リアルタイム波形、録音バックアップ保存ボタンを提供します。
5. **既存スプレッドシート（GAS）との完全な後方互換 ＋ 排他制御（`LockService`）**
   - 既存の carecore スプレッドシートの接続先 URL をそのまま引き継ぎ、`LockService` による同時書き込み保護と 50,000文字上限保護を備えています。

## 🚀 Vercel 環境変数の設定（推奨）

1. Vercel の対象プロジェクト（`coops-minutes-ai`）の **Settings ➔ Environment Variables** を開きます。
2. `GEMINI_API_KEY` に Google AI Studio で取得した API キー（`AIzaSy...`）を設定して再デプロイします。
   - ※未設定の場合でも、画面右上の「⚙️設定」からAPIキーを入力するか、従来の GAS スクリプトプロパティ経由へ自動フォールバックして動作します。
